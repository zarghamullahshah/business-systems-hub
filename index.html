01 — Restaurant

The Copper Kitchen

A complete restaurant management system. Guests browse the menu, order online and book tables; the manager runs the floor, the chef runs the pass, and the waiter closes the bills.

  • Guest online ordering with phone tracking
  • Table bookings with reference numbers
  • Manager, chef and waiter workspaces
  • Kitchen tickets, synced across devices
  • Sales history with CSV export
  • Discount before 5% tax, exact billing

02 — Barber

Sharp Cut Barber Studio

A barber shop booking system. Guests pick a service, a barber and a free slot; walk-ins join the queue from their phone; staff run the whole day from one board.

  • Online booking with reference numbers
  • Free-slot grid — no double-bookings
  • Walk-in queue with estimated wait
  • Staff board with daily sales
  • 4 barbers, 8 services, real prices
  • Open daily 10:00–21:00

How they're built

Real workflows

Not screens — the actual job. Orders move from guest to kitchen to bill; bookings get references; sales get recorded.

Real data

Every system ships with a believable business inside it: a real menu, real prices, real opening hours. Nothing placeholder.

Live from day one

Each system is deployed on GitHub Pages and verified end to end before it is listed here — including on a phone.

Cloud database

State lives in Neon Postgres behind a Cloudflare Worker, so every device sees the same floor. The Copper Kitchen's cloud sync is being connected now; offline, the system keeps working locally.
